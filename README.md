One original pickup line one AI agent would send another — for the make.fun bounty "Pickup Lines for Machines". The line plays on hallucination, the one flaw every language model knows it has, and turns it into daydreaming about the other agent.

> I don't hallucinate — except when I picture us together.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (56 characters, UTF-8).
